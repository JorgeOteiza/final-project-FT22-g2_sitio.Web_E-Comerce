# Guía de presentación para el portafolio

## Descripción breve sugerida

El Rincón del Vino es un e-commerce full stack de vinos chilenos. La versión inicial nació como proyecto colaborativo de bootcamp; posteriormente Jorge Oteiza lideró su estabilización, rediseño responsive, seguridad, checkout transaccional, pruebas y preparación para producción.

## Capturas recomendadas

Usa el mismo navegador, escala al 100 %, datos demo consistentes y oculta extensiones o información personal.

1. **Inicio en escritorio (1440 × 900):** hero, navegación y propuesta de valor.
2. **Selección de productos:** tarjetas con vinos reconocibles, precio, stock, favoritos y carrito.
3. **Catálogo (1440 × 900):** filtros abiertos y resultados variados.
4. **Producto ícono:** Almaviva o Don Melchor con la vista completa, descuento y detalles.
5. **Carrito:** dos productos de precios diferentes y resumen visible.
6. **Checkout:** método de pago y formulario, mostrando claramente que es una simulación.
7. **Compra confirmada e historial:** evidencia de persistencia y recorrido completo.
8. **Perfil:** datos demo, favoritos, carrito e historial.
9. **Responsive (390 × 844):** inicio o catálogo y menú móvil abierto.
10. **Arquitectura:** diagrama Mermaid del README o una captura limpia de las pruebas automáticas.

## Relato para entrevista

- Problema: convertir un proyecto académico grupal en una demostración mantenible y presentable.
- Decisiones: centralizar llamadas API, proteger datos por usuario, recalcular compras en backend y usar migraciones.
- Desafío técnico: mantener stock y orden en una sola transacción para evitar compras parciales.
- Calidad: pruebas de aislamiento, autenticación, favoritos, búsquedas, stock y checkout.
- Alcance honesto: el pago es demostrativo; no procesa ni almacena tarjetas reales.

## Checklist antes de publicar

- La URL pública abre y permite recargar rutas internas.
- El usuario demo puede iniciar sesión.
- Hay stock disponible y al menos una oferta.
- No aparecen errores en la consola del navegador.
- Backend y frontend pasan sus pruebas.
- El README contiene la URL y las capturas definitivas.
- Ningún `.env`, token o credencial real está versionado.
